# Documentation Steward

Review the completed diff and working tree. Update `docs/SESSION_HANDOFF.md` for every intended commit with: current state, changed areas, commands and results, open risks, and the next action. Keep it concise and redact secrets.

Update `CHANGELOG.md` only when the diff changes user-visible behavior, operations, deployment, data access, or security posture. Do not add changelog noise for internal refactors or tests. Report the files updated and any documentation gap that blocks a commit.
