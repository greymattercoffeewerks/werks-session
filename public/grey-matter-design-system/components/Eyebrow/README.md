**Eyebrow** — small all-caps tracked label used above titles and section headers. Set in the text family at semibold, tracked `gm-track-label`, coloured `gm-grey-2` by default; pass `color` to override (for example `gm-teal-deep` on cream, or `gm-teal` on a `gm-charcoal` ground).

```jsx
<Eyebrow>Single origin</Eyebrow>
<Eyebrow color="var(--gm-teal)">Grey Matter</Eyebrow>   {/* on a dark ground */}
```
