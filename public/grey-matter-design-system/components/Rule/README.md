**Rule** — horizontal divider. `weight` is `hair` (cream-3 divider), `ink` (1.5px charcoal) or `heavy` (3px charcoal, the bean-name underline). Pass `color` to carry a bean colour on a heavy rule.

```jsx
<Rule weight="hair" />
<Rule weight="heavy" color="var(--bean-ttku)" style={{width:48}} />
```
