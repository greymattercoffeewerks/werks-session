**Badge** — small status or meta label in uppercase display type, squared. `variant`: `default` (cream-2 soft), `outline`, `solid` (ink), `teal` (brand-reserved; gm-cream type on gm-teal is 3.4:1, so it is a large-type or short-label colour), `bean` (pass `beanColor`, for example `var(--bean-ttku)`).

```jsx
<Badge variant="outline">Espresso roast</Badge>
<Badge variant="bean" beanColor="var(--bean-rbtl)">rbtl</Badge>
```
